# About

This repository contains my complete documentation, notes, source code, screenshots, and assignments completed during the **VSD Workshop**.

The workshop focuses on practical VLSI design concepts using Linux and industry-standard open-source EDA tools inside a Virtual Machine.

Everything has been organized day-wise to make navigation simple.

---

# Workshop Objectives

- Learn Linux commands required for VLSI workflows
- Understand Digital Design concepts
- Write Verilog HDL modules
- Simulate designs using Icarus Verilog
- Generate waveforms using GTKWave
- Learn the ASIC Design Flow
- Document the complete learning process
